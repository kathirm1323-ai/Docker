
# Docker Learning Notes

This repository contains my personal learning notes and practical command references for Docker and containerization. It covers essential Docker concepts, image and container management, volume handling, Docker Compose, Dockerfile instructions, and Docker Ignore.

The notes include practical examples using a Python authentication API to understand how applications are packaged, configured, and executed inside containers.

### Topics Covered

* Docker images, containers, volumes, and bind mounts
* Dockerfile instructions and image building
* Essential Docker commands for managing images, containers, and volumes
* Port mapping and environment variable configuration
* Docker Compose for managing multi-container applications
* Docker Ignore for excluding unnecessary files and sensitive configurations
* Docker installation and WSL integration
* Practical commands and examples for application containerization

These notes serve as a quick reference for my ongoing learning journey in Docker, containerization, and DevOps.
